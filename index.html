Akses Cepat Modul Pembelajaran

Pintasan langsung ke materi ujian penting kelas 6:

🪐 Paket Tata Surya (52 Soal)

Planet, rotasi, revolusi, dan gerhana lengkap.

📐 Pecahan & Desimal (10 Soal)

Operasi hitung pecahan campuran dan desimal.

🗺️ Rasio & Skala Peta (10 Soal)

Perbandingan senilai dan jarak pada denah.

📖 Teks Eksplanasi & Fakta/Opini

Struktur teks ilmiah dan kalimat efektif.

Petunjuk Penggunaan

  • Klik Mata Pelajaran untuk melihat kartu modul mirip format Psikogram.
  • Gunakan Bank Soal untuk memfilter soal dengan input kolom langsung di bawah header.
  • Pilih Mode Kuis Anak untuk latihan interaktif dengan efek suara.
  • Gunakan Generator Ujian untuk mencetak naskah lembar soal PDF siap pakai.

Cadangan & Impor Bank Soal

Anda dapat mencadangkan seluruh bank soal ke file Excel/CSV atau JSON, serta mengimpor paket kuis baru dalam format HTML maupun JSON.

1. Ekspor ke Excel (CSV)

Unduh seluruh butir soal dalam format tabel spreadsheet Excel.

2. Cadangan Lengkap (JSON)

Simpan seluruh bank soal dan struktur data dalam format JSON standar.

3. Impor File (HTML / JSON)

Unggah file kuis HTML atau JSON untuk ditambahkan otomatis.
